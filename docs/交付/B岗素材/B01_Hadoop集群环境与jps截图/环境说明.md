# Hadoop 集群环境说明（苏静 · B 岗）

## 一、组件版本

| 组件 | 版本 | 职责 |
|---|---|---|
| Hadoop | 3.3.6 | HDFS 分布式存储 + YARN 资源调度 + MapReduce 计算 |
| Hive | 4.0.0 | 数仓分层建模（ODS/DWD/DWS/ADS），HiveServer2 提供 SQL 入口 |
| Spark | 3.4 | 多维聚合与 ADS 指标计算（Spark SQL / Spark MLlib） |
| Flume | 1.11 | 数据接入层（A 岗） |
| Sqoop | 1.4.7 | Hive ADS → MySQL 导出（B 岗） |
| MySQL | 8.0 | ADS 落地业务库（D 岗读取） |
| Redis | 7 | 接口缓存（D 岗） |

## 二、部署形态

Docker Compose 单机多容器，`scripts/start_all.sh` 一键启动，
内置 full / app / native 三层自动降级（Docker 引擎异常时回退到应用层直连 MySQL 静态数据）。

## 三、Hadoop 六大进程（jps 期望输出）

| 进程 | 作用 |
|---|---|
| NameNode | HDFS 元数据管理 |
| DataNode | HDFS 数据块存储 |
| SecondaryNameNode | 元数据合并（checkpoint） |
| ResourceManager | YARN 资源调度 |
| NodeManager | YARN 节点资源与容器管理 |
| JobHistoryServer | MapReduce 作业历史记录（Job 截图来源） |

## 四、启动与验证

```bash
# 一键启动全套
bash scripts/start_all.sh

# 验证 Hadoop 进程
jps

# 验证 HDFS
hdfs dfs -ls /

# 验证 Hive
beeline -u jdbc:hive2://localhost:10000 -e "show databases;"

# 端到端体检
bash scripts/smoke_test.sh
```

## 五、关键结论

> 集群采用容器化单机多进程部署，六个核心进程（NameNode/DataNode/SecondaryNameNode/
> ResourceManager/NodeManager/JobHistoryServer）全部就绪，可在任意一台 8GB 内存笔记本复现，
> 这是本系统"可移植性"的工程保障。
