# 清洗报告一 · 缺失值与零值统计

## 一、检查目的
区分「真实零值」与「缺失零值」。充电场景中零值可能是「该小时该分区无充电活动」的真实业务状态，
也可能是采集故障导致的缺失，二者处理方式不同：前者保留标记，后者需隔离。

## 二、实测结果

| 指标 | 总行数 | 零值行数 | 零值占比 | 缺失值（NaN） |
|---|---|---|---|---|
| occupancy | 1,194,600 | 32,307 | 2.70% | 0 |
| duration | 1,194,600 | 65,365 | 5.47% | 0 |
| volume | 1,194,600 | 65,365 | 5.47% | 0 |
| volume_11kw | 1,194,600 | 65,169 | 5.46% | 0 |
| e_price | 1,194,600 | 0 | 0.00% | 0 |
| s_price | 1,194,600 | 8,886 | 0.74% | 0 |

## 三、结论
duration / volume 各有 65,365 行零值且数量完全一致，说明零值来自同一批「深夜无充电活动」时段，
属**真实业务状态而非数据缺陷**。按「先修复后丢弃」原则予以保留并标记 `is_zero=1`，
缺失值（NaN）为 0，无需剔除。
