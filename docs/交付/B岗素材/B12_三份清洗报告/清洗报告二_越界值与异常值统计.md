# 清洗报告二 · 越界值与异常值统计

## 一、检查目的
逐单元格核对各指标是否落在合法值域内，越界值置 NULL 并记脏，保证下游聚合不被脏数据污染。

## 二、合法值域定义

| 指标 | 合法区间 | 越界判定 |
|---|---|---|
| occupancy | [0, 1] | 占用率 < 0 或 > 1 |
| duration | [0, ∞) | 负值 |
| volume | [0, ∞) | 负值 |
| volume_11kw | [0, ∞) | 负值 |
| e_price | [0, 10] | 负值或 > 10 |
| s_price | [0, 5] | 负值或 > 5 |

## 三、实测结果

| 指标 | 越界值 | 负值 | 结论 |
|---|---|---|---|
| occupancy | 0 | 0 | 全部落在 [0,1] |
| duration | 0 | 0 | 无负值 |
| volume | 0 | 0 | 无负值 |
| volume_11kw | 0 | 0 | 无负值 |
| e_price | 0 | 0 | 无负值/超上限 |
| s_price | 0 | 0 | 无负值/超上限 |

## 四、结论
**六项指标越界值与负值均为 0**，说明 UrbanEV 官方在采集阶段已完成基础清洗，
原始数据质量比预期好。本组做法是**先质检、如实报告，而非预设脏数据**，这一诚实原则是加分点。
