## 二、清洗前后对比说明（PPT 第 5 页用）

| 检查项 | 清洗前 | 清洗后 | 处理方式 |
|---|---|---|---|
| 越界值（occupancy>1 等） | 0 | 0 | 阈值判定，越界置 NULL 记脏 |
| 负值（duration/volume/e_price） | 0 | 0 | 负值置 NULL 记脏 |
| 重复时间戳 | 0 | 0 | 保留首条 |
| 非法/缺失时间戳 | 0 | 0 | 丢弃该行 |
| 零值（疑似缺失） | 32,307~65,365 | 保留 | 标记 is_zero=1，不丢弃 |

## 三、一句话结论

> 清洗前 6 指标各 1,194,600 行，越界值与重复时间戳均为 **0**（UrbanEV 采集阶段已预清洗）；
> 零值集中在深夜无充电时段，属真实业务状态，按「先修复后丢弃」原则**保留并标记 is_zero=1**，
> 故清洗后有效行数仍为 1,194,600，但脏数据已全部隔离、可追溯。
