## 配音稿

完整配音纯文本在 `scripts/video_make_audio.py` 的 `NARRATION` 列表（40 段，2050 字）。

**换成真人配音的操作**：
1. 按上表的镜头顺序，把每段录成独立音频，命名 `L01.mp3` … `L40.mp3`；
2. 放到 `%TEMP%/uev_video_audio/` 目录；
3. 跑 `python scripts/video_make_audio.py measure` —— 会自动实测每段真实时长、
   回填镜头停留时间、同步本分镜脚本的时间轴；
4. 跑 `python scripts/video_build.py` 重新合成。

> 录制建议：44.1 kHz 单声道或立体声 WAV/MP3，语速约 4–5 字/秒，
> 每段开头留 0.3 秒静音。段落之间不用刻意留白，脚本会自动补呼吸间隙。
