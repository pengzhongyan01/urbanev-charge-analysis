| 指标 | 清洗前 | 清洗后 | 处理动作 |

| 总记录数 | 1,196,000 | 1,196,000 | — |
| 零值记录 | 52,341 | — | 标记 `is_zero` |
| 越界记录 | 1,203 | 0 | 区间校验置 NULL |
| 无效时间戳 | 47 | 0 | 剔除 |
| **有效率** | **95.6%** | **99.97%** | |

> 💡 **答辩高频问题预案**：
> "为什么要用 MapReduce 而不是 Hive SQL？"

## 第 8 页 · 创新点①供需失衡指数 + ②电价弹性

**版式**：左右两栏，每栏一个公式 + 一张图

### 左栏 · 创新点① 峰谷供需失衡指数

**问题背景**：
> "不同分区充电桩基数差异巨大（4 ~ 446 个），直接比较绝对量不公平。"

**公式**：
```
D(z,t) = 该分区需求占全市同期需求的比例
S(z,t) = 该分区运力占全市同期运力的比例

★ I(z,t) = D(z,t) − S(z,t)
```

**结论**：
> "全市 275 个分区中，**23 个分区在晚高峰存在明显供需失衡**，
> 失衡指数最高达 0.0142，集中在南山、福田 CBD。"

**配图**：失衡指数 TOP10 横向柱状图（正负用橙/绿区分）

### 右栏 · 创新点② 分时电价弹性分析

**问题背景**：
> "分时电价到底有没有真的削峰填谷？政策说有，数据能否证明？"

**方法**：
```
σ_price(z) = 该分区电价时序标准差
  σ > 阈值 → 分时电价区（TOU）
  σ ≈ 0    → 固定电价区（FLAT）

★ 弹性 = 高峰时段(17-19时)平均占用率 − 低谷时段(0-6时)平均占用率
  该值越小 → 峰谷差被压得越平 → 削峰效果越好
```

**结论**：
> "分时电价区的峰谷差为 **0.213**，固定电价区为 **0.347**，
> 分时电价的削峰填谷效果**量化可见**。
> （说明：这是观测性关联，不做因果推断）"

**配图**：TOU vs FLAT 双曲线对比图

**页脚**：主讲 姬婷婷　协作 彭忠燕

## 第 9 页 · 创新点③ 需求预测 + 布点建议

**版式**：左预测曲线，右建议清单表

### 左栏 · 充电需求预测

**方法**：
```
预测值 = 同星期同小时的历史均值 × 趋势修正因子 γ
γ = 近 7 天均值 / 全期均值
```

**回测**：最后 7 天作验证集，前 174 天训练

**结论**：
> "分区级周同环比预测，**MAPE = 11.3%**。
> 出于工程可复现性与答辩现场可演示性考虑，采用统计方法而非深度学习，
> 深度序列模型列入后续展望。"

**配图**：预测值 vs 实际值 折线图 + MAPE 标注

### 右栏 · 布点扩容建议

**规则**：
```
建议新增桩数 = ⌈峰值失衡指数 × 现有桩数 × 0.3⌉
优先级 = 按峰值失衡指数降序
```

**结论**：
> "输出 **18 个分区的扩容建议**，TOP3 建议新增 12 / 9 / 8 个桩，
> 均集中在晚高峰需求远超运力份额的 CBD 分区。"

**配图**：建议清单表格（前 10 条，带优先级配色）
