## 常见问题

**Q：PPT 的风格我来定还是你定？**
A：我定，全组统一。你只管内容。

**Q：我的图不好看怎么办？**
A：不用美化，把原始截图给我就行，排版是我的事。

**Q：我在 PPT 上有署名吗？**
A：有。每页页脚会标 `主讲：X　制作：A　数据支持：Y`，你的名字会出现。

**Q：内容我想改怎么办？**
A：随时告诉我改哪页，改完我更新 PPT。你也可以自己动手改，改完告诉我一声避免冲突。

**Q：创新点那两页讲不完 2 分钟怎么办？**
A：把讲稿要点写进素材文件，我排版时会控制文字量。答辩话术我们一起对一遍。
