## 四层职责

| 层 | 职责 | 谁看 |
|---|---|---|
| **ODS** | 贴源存放，字段与源 CSV 一一对应，**不做任何加工** | B |
| **DWD** | 清洗 + 补齐维度的**明细事实表**：一行 = 一个分区在一个小时 | B / E |
| **DWS** | 轻度汇总：按天聚合、滚动均值、峰谷标识、分区供给画像 | B / E |
| **ADS** | 应用指标层：**一张表对应前端一个图表**，前端只查 ADS | B / D / C |

---

## 库表命名规范

```
库名：ev

ODS 层  ev.ods_<源文件名>              例：ev.ods_occupancy
维表    ev.dim_<表名>                   例：ev.dim_zone_info
DWD 层  ev.dwd_<主题>_<粒度>            例：ev.dwd_zone_hour
DWS 层  ev.dws_<主题>_<粒度>            例：ev.dws_zone_day
ADS 层  ev.ads_<主题>                   例：ev.ads_imbalance_index
```

## 表结构定义

### ODS 层（外部表，直接指向 HDFS）

```sql
CREATE EXTERNAL TABLE IF NOT EXISTS ev.ods_occupancy (
  zone_id   INT,
  hour_ts   BIGINT,
  occupancy DOUBLE
)
PARTITIONED BY (dt STRING)
ROW FORMAT DELIMITED FIELDS TERMINATED BY ','
STORED AS TEXTFILE
LOCATION '/user/hadoop/urbanev/ods/occupancy';
```

> 同模式：`ods_duration`、`ods_volume`、`ods_volume_11kw`、`ods_e_price`、`ods_s_price`

**维表（无分区）**：
```sql
CREATE EXTERNAL TABLE IF NOT EXISTS ev.dim_zone_info (
  zone_id   INT,
  lng       DOUBLE,
  lat       DOUBLE,
  pile_cnt  INT,
  capacity  DOUBLE,
  area      DOUBLE,
  perimeter DOUBLE,
  in_cbd    INT
)
ROW FORMAT DELIMITED FIELDS TERMINATED BY ','
STORED AS TEXTFILE
LOCATION '/user/hadoop/urbanev/dim/inf';
```

### DWD 层

```sql
CREATE TABLE IF NOT EXISTS ev.dwd_zone_hour (
  zone_id       INT    COMMENT '分区编号',
  hour_ts       BIGINT COMMENT '时间戳(秒)',
  dt            STRING COMMENT '日期分区',
  hour_of_day   INT    COMMENT '0-23',
  is_weekend    INT    COMMENT '是否周末',
  occupancy     DOUBLE COMMENT '充电桩占用率(%)',
  duration_h    DOUBLE COMMENT '充电总时长(hour)',
  volume_kwh    DOUBLE COMMENT '充电总电量(kWh,额定功率口径)',
  volume_11kw   DOUBLE COMMENT '充电总电量(kWh,11kW车型口径)',
  e_price       DOUBLE COMMENT '电价(元/kWh)',
  s_price       DOUBLE COMMENT '服务费(元/kWh)',
  pile_cnt      INT    COMMENT '分区充电桩数',
  area          DOUBLE COMMENT '分区面积(m2)',
  in_cbd        INT    COMMENT '是否CBD',
  temp          DOUBLE COMMENT '温度(来自最近气象站)',
  rainfall      DOUBLE COMMENT '降水(来自最近气象站)',
  is_peak       INT    COMMENT '是否峰时段',
  is_valley     INT    COMMENT '是否谷时段'
)
COMMENT '清洗后的分区小时明细事实表'
PARTITIONED BY (dt STRING)
STORED AS ORC
TBLPROPERTIES ('orc.compress'='SNAPPY');
```

**这张表是 E 岗所有指标的计算基础。**

### DWS 层

```sql
CREATE TABLE IF NOT EXISTS ev.dws_zone_day (
  zone_id          INT,
  dt               STRING,
  demand_intensity DOUBLE COMMENT '日均需求强度',
  demand_ma7       DOUBLE COMMENT '7日滚动均值',
  peak_demand      DOUBLE COMMENT '日峰值需求',
  peak_valley_gap  DOUBLE COMMENT '峰谷差',
  saturation       DOUBLE COMMENT '饱和度',
  total_volume     DOUBLE COMMENT '日总电量',
  is_weekend       INT
)
PARTITIONED BY (dt STRING)
STORED AS ORC;
```

### ADS 层（每张表 = 前端一个图表）

```sql
-- 对应：供需失衡热力图 + Top-N 榜
CREATE TABLE IF NOT EXISTS ev.ads_imbalance_index (
  zone_id         INT,
  hour_of_day     INT,
  dt              STRING,
  demand_intensity DOUBLE,
  baseline_demand  DOUBLE,
  imbalance_index  DOUBLE,
  relative_imbalance DOUBLE,
  advice_type      STRING
)
PARTITIONED BY (dt STRING)
STORED AS ORC;

-- 对应：电价弹性对比
CREATE TABLE IF NOT EXISTS ev.ads_price_elasticity (
  zone_id            INT,
  is_tou_pricing     INT,
  peak_valley_gap    DOUBLE,
  price_elasticity   DOUBLE,
  avg_demand_peak    DOUBLE,
  avg_demand_valley  DOUBLE
)
PARTITIONED BY (dt STRING)
STORED AS ORC;

-- 对应：预测曲线
CREATE TABLE IF NOT EXISTS ev.ads_forecast (
  zone_id      INT,
  forecast_ts  BIGINT,
  forecast     DOUBLE,
  lower_bound  DOUBLE,
  upper_bound  DOUBLE,
  method       STRING,
  mape         DOUBLE
)
PARTITIONED BY (dt STRING)
STORED AS ORC;

-- 对应：布点建议看板
CREATE TABLE IF NOT EXISTS ev.ads_expansion_advice (
  zone_id         INT,
  advice_type     STRING,
  suggest_count   INT,
  basis           STRING,
  expected_effect STRING
)
PARTITIONED BY (dt STRING)
STORED AS ORC;
```

## MySQL 侧（供 Spring Boot 查询）

```sql
-- 后端直接查询这些表
CREATE TABLE IF NOT EXISTS ev_ads_imbalance (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  zone_id INT, hour_of_day INT, dt VARCHAR(20),
  demand_intensity DOUBLE, baseline_demand DOUBLE,
  imbalance_index DOUBLE, relative_imbalance DOUBLE,
  advice_type VARCHAR(32),
  KEY idx_zone_dt (zone_id, dt),
  KEY idx_dt_hour (dt, hour_of_day)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE IF NOT EXISTS ev_ads_advice (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  zone_id INT, advice_type VARCHAR(32), suggest_count INT,
  basis VARCHAR(255), expected_effect VARCHAR(255),
  KEY idx_type (advice_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE IF NOT EXISTS ev_user (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  username VARCHAR(64) UNIQUE,
  password VARCHAR(128),
  role VARCHAR(32),
  create_time DATETIME
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

**Sqoop 导出示例**：
```bash
sqoop export \
  --connect jdbc:mysql://localhost:3306/urbanev \
  --username root --password xxx \
  --table ev_ads_imbalance \
  --hcatalog-table ev.ads_imbalance_index \
  --hcatalog-database ev \
  --hcatalog-partition-keys dt \
  --hcatalog-partition-values 2022-10 \
  --m 1
```

## 分区与分桶策略

| 层 | 分区 | 分桶 |
|---|---|---|
| ODS | `dt`（月份，yyyy-MM） | 无 |
| DWD | `dt`（月份） | `zone_id`，16 桶 |
| DWS | `dt`（月份） | `zone_id`，16 桶 |
| ADS | `dt`（月份） | `zone_id`，16 桶 |
| MySQL | — | 索引 `idx_zone_dt`、`idx_dt_hour` |
