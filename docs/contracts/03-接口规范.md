## 一、通用约定

### 1.1 基础信息

| 项 | 约定 |
|---|---|
| 基础路径 | `/api` |
| 本机直连 | `http://localhost:8080/api` |
| Docker 部署 | 经 Nginx 反代，`http://localhost/api`（前端无需改动） |
| 请求方法 | GET（全部为查询，无写操作） |
| 编码 | UTF-8 |
| 响应格式 | `application/json` |

### 1.2 统一响应结构

```json
{
  "code": 200,
  "message": "success",
  "data": { },
  "timestamp": 1731993600000
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | int | 200 成功；400 参数错误；404 资源不存在；500 服务异常 |
| `message` | string | 提示信息，前端失败时直接展示 |
| `data` | object/array | 数据载荷 |
| `timestamp` | long | 服务端时间戳（毫秒） |

> 🔴 **前端约定**：只判断 `code === 200`，不解析异常栈。
> 后端已配置 `GlobalExceptionHandler` 统一处理异常。

### 1.3 公共查询参数

所有图表接口支持以下可选参数：

| 参数 | 类型 | 示例 | 说明 |
|---|---|---|---|
| `startDate` | string | `2022-09-01` | 起始日期 |
| `endDate` | string | `2023-02-28` | 结束日期 |
| `hourRange` | string | `17-19` | 时段：`0-6` / `7-9` / `10-16` / `17-19` / `20-23` |
| `zoneId` | string | `308` | 分区编号，空表示全部 |
| `priceType` | string | `TOU` | 电价类型：`TOU` / `FLAT`，空表示全部 |

### 1.4 缓存策略

| 接口类型 | 缓存 | TTL |
|---|---|---|
| `/dashboard/kpi` | Redis `uev:kpi:{hash}` | 300 秒 |
| `/zones/occupancy` | Redis `uev:zone_occ:{hash}` | 600 秒 |
| `/charts/*` | Redis `uev:chart:{name}:{hash}` | 120 秒 |

> 💡 **缓存 key 要包含全部筛选参数**（用参数哈希），
> 否则改筛选条件会拿到旧数据——这是最常见的缓存 bug。

## 二、接口清单

### 2.1 健康检查 `GET /api/health`

**用途**：启动脚本判断就绪、冒烟测试体检、前端右上角状态指示

**请求参数**：无

**响应**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "status": "UP",
    "timestamp": "2026-11-19T14:30:00",
    "application": "uev-charge-analysis",
    "version": "1.0.0",
    "regionCount": 275,
    "components": {
      "mysql": "UP",
      "redis": "UP"
    }
  }
}
```

> ⚠️ `regionCount` 默认值 96 需在 `application.yml` 中改为 **275**（`uev.data.region-count`）。

---

### 2.2 KPI 概览 `GET /api/dashboard/kpi`

**用途**：首页 5 个指标卡

**请求参数**：公共查询参数（全部可选）

**响应**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "stationCount": 275,
    "pileCount": 23441,
    "avgOccupancy": 0.3421,
    "totalVolume": 12876543.21,
    "avgDuration": 2.8765,
    "imbalanceZones": 23,
    "regions": [
      { "zoneId": "308", "pileCount": 446 },
      { "zoneId": "302", "pileCount": 312 }
    ]
  }
}
```

| 字段 | 类型 | 前端用途 | 对应指标 |
|---|---|---|---|
| `stationCount` | int | KPI 卡"充电站总数" | — |
| `pileCount` | int | 分区下拉框副标题 | — |
| `avgOccupancy` | double | KPI 卡"平均占用率"（×100） | M3 |
| `totalVolume` | double | KPI 卡"累计充电量" | M5 |
| `avgDuration` | double | KPI 卡"平均充电时长" | M6 |
| `imbalanceZones` | int | KPI 卡"供需失衡分区数" | 创新点① |
| `regions` | array | 填充分区下拉框 | — |

> ⚠️ **单位**：前端会自己 ×100 转百分比，后端返回**原始比例**。

### 2.4 24 小时供需曲线 `GET /api/charts/hourly`

**响应**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "hourly": [
      {
        "hourOfDay": 0,
        "avgOccupancy": 0.1523,
        "demandShare": 0.0287,
        "supplyShare": 0.0354,
        "gap": -0.0067,
        "imbalance": -0.0067

    ]
  }
}
```

| 字段 | 类型 | 对应指标 |
|---|---|---|
| `hourOfDay` | int | 0-23 |
| `avgOccupancy` | double | M3 |
| `demandShare` | double | 创新点① 的 D(z,t) |
| `supplyShare` | double | 创新点① 的 S(z,t) |
| `gap` / `imbalance` | double | 创新点① 的 I(z,t) |

        "supplyShare": 0.0301,

| 字段 | 类型 | 说明 |
|---|---|---|

| `demandShare` / `supplyShare` | double | D 与 S，用于 tooltip 解释 |

### 2.6 电价弹性对比 `GET /api/charts/price-elasticity`

**用途**：★ 创新点② 双曲线图

**响应**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "tou": [
      { "hourOfDay": 18, "avgOccupancy": 0.5234, "zoneCount": 112, "avgPriceGap": 0.6821 }
    ],
    "flat": [
      { "hourOfDay": 18, "avgOccupancy": 0.7102, "zoneCount": 163, "avgPriceGap": 0.0234 }
    ],
    "summary": {
      "touElasticity": 0.2134,
      "flatElasticity": 0.3468,
      "touGap": 0.6821,
      "flatGap": 0.0234,
      "touZoneCount": 112,
      "flatZoneCount": 163
    }
  }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `tou` / `flat` | array | 两组按小时的占用率序列 |
| `avgOccupancy` | double | 该组该小时平均占用率 |
| `zoneCount` | int | 该组分区数 |
| `avgPriceGap` | double | 该组平均峰谷电价差（M12） |
| `summary.touElasticity` | double | TOU 组峰谷差（越小越好） |
| `summary.flatElasticity` | double | FLAT 组峰谷差 |

> 💡 **summary 是给 PPT 用的**：前端把它显示在图表标题右侧，
> 答辩时直接说"TOU 组 0.21，FLAT 组 0.35"。

### 2.7 需求预测 `GET /api/charts/forecast`

**用途**：★ 创新点③ 预测曲线

**请求参数**：公共查询参数 + `zoneId`（指定分区则只返回该分区）

**响应**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "mape": 11.32,
    "series": [
      {
        "zoneId": "308",
        "forecastDate": "2023-02-22",
        "hourOfDay": 0,
        "predictVolume": 1234.56,
        "actualVolume": 1189.23
      }
    ]
  }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `mape` | double | 全局平均绝对百分比误差（%） |
| `predictVolume` | double | 预测电量 kWh |
| `actualVolume` | double | 实际电量 kWh（回测期） |

---

### 2.8 布点扩容建议 `GET /api/charts/suggestions`

**用途**：★ 创新点③ 建议清单表格

**请求参数**：公共查询参数 + `limit`（int，默认 30）

**响应**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "suggestions": [
      {
        "zoneId": "308",
        "longitude": 113.9308,
        "latitude": 22.5333,
        "currentPiles": 446,
        "suggestedPiles": 12,
        "priority": 1,
        "reason": "该分区在 18 时出现供需失衡（失衡指数 0.0111），现有 446 个充电桩，建议新增 12 个桩",
        "avgOccupancy": 0.6821,
        "peakGap": 0.0111
      }
    ]
  }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `currentPiles` | int | 现有桩数 |
| `suggestedPiles` | int | 建议**新增**桩数（不是总数！） |
| `priority` | int | 1 = 最高优先级 |
| `reason` | string | **完整中文句子**，前端直接展示 |
