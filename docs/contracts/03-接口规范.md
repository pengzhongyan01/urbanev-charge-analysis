## 使用说明

**C 的前端代码只能调用本文件里列出的接口和字段。** 不要自己发明路径或字段名。

统一响应格式（所有接口一致）：
```json
{
  "code": 200,
  "message": "success",
  "data": { }
}
```

---

## 接口清单

### 1. 分区列表

```
GET /api/zone/list
```
**用途**：前端地图初始化、筛选器下拉选项
**出参**：
```json
{
  "code": 200,
  "data": [
    { "zoneId": 1, "lng": 114.05, "lat": 22.53, "pileCnt": 86, "area": 1250000, "inCbd": 1 },
    ...
  ]
}
```

---

### 2. 需求热力图数据

```
GET /api/indicator/heatmap?date=2022-10-01
```
**参数**：`date`（可选，yyyy-MM-dd，缺省返回全时段聚合）
**出参**：
```json
{
  "code": 200,
  "data": {
    "zoneIds": [1, 2, 3],
    "hours": [0, 1, 2, ...],
    "values": [[0.31, 0.28, ...], ...]   // [zoneIndex][hourIndex]
  }
}
```

---

### 3. 供需失衡指数

```
GET /api/indicator/imbalance?date=2022-10-01&topN=20
```
**参数**：`date`（可选）、`topN`（可选，默认 20）
**出参**：
```json
{
  "code": 200,
  "data": {
    "matrix": { "zoneIds": [...], "hours": [...], "values": [[...]] },
    "topList": [
      { "zoneId": 137, "zoneName": "南山科技园", "peakImbalance": 1.82,
        "peakHour": 19, "pileCnt": 64, "advice": "建议扩容" },
      ...
    ]
  }
}
```

---

### 4. 分时电价弹性对比

```
GET /api/indicator/price-elasticity
```
**出参**：
```json
{
  "code": 200,
  "data": {
    "touZones": [12, 45, ...],          // 分时电价区
    "fixedZones": [3, 8, ...],          // 固定电价区
    "touAvgPeakValley": 2.14,
    "fixedAvgPeakValley": 3.67,
    "reductionPercent": 41.7,
    "elasticity": [ { "zoneId": 12, "epsilon": -0.68 } ]
  }
}
```

---

### 5. 天气影响

```
GET /api/indicator/weather?date=2022-10-01
```
**出参**：按温度/降水分档的充电量分布
```json
{
  "code": 200,
  "data": {
    "byTemperature": [ { "range": "20-25℃", "avgDemand": 1.42, "zoneCount": 34 } ],
    "byRainfall":   [ { "level": "无雨", "avgDemand": 1.55 } ]
  }
}
```

---

### 6. 预测结果

```
GET /api/forecast/list?zoneId=137&days=7
```
**出参**：
```json
{
  "code": 200,
  "data": [
    { "zoneId": 137, "hourTs": 1756000000, "forecast": 1.28,
      "lowerBound": 1.05, "upperBound": 1.51, "method": "sameWeekdaySmooth" },
    ...
  ]
}
```

---

### 7. 布点扩容建议

```
GET /api/advice/list?type=all
```
**参数**：`type`（可选：`expand`扩容 / `tou`错峰 / `dispatch`调度 / `all`）
**出参**：
```json
{
  "code": 200,
  "data": [
    { "zoneId": 137, "zoneName": "南山科技园", "adviceType": "expand",
      "suggestCount": 12, "basis": "峰值失衡指数 1.82，超全市 P90",
      "expectedEffect": "预计高峰排队时长下降 35%" },
    ...
  ]
}
```

---

### 8. 导出 Excel

```
GET /api/advice/export?type=all
```
**返回**：xlsx 文件流，`Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`

---

### 9. 登录

```
POST /api/auth/login
Content-Type: application/json
{ "username": "admin", "password": "xxx" }
```
**出参**：
```json
{ "code": 200, "data": { "token": "eyJhbGci...", "role": "admin", "username": "admin" } }
```
**鉴权方式**：后续请求带 `Authorization: Bearer <token>`

---

### 10. 数据字典

```
GET /api/dict/list
```
**用途**：前端"数据来源说明"页，展示 UrbanEV 数据集信息与各 CSV 字段说明。

## 统一错误码

| code | 含义 |
|---|---|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录或 token 失效 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 通用查询参数

| 参数 | 类型 | 说明 |
|---|---|---|
| `date` | string | yyyy-MM-dd |
| `startDate` / `endDate` | string | 日期区间 |
| `zoneId` | int | 分区编号 |
| `hour` | int | 0~23 |
