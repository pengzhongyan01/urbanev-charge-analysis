## 指标清单

### 指标 1：分区小时充电需求强度

| 项 | 内容 |
|---|---|
| 名称 | `demand_intensity` |
| 公式 | `D(z,t) = duration_h(z,t) / pile_cnt(z)` |
| 含义 | 单位桩在单位时间内的充电时长，反映需求强度 |
| 来源表 | `ev.dwd_zone_hour` JOIN `ev.dim_zone_info` |
| SQL | `SELECT zone_id, hour_ts, duration_h / pile_cnt AS demand_intensity FROM ev.dwd_zone_hour d JOIN ev.dim_zone_info i USING(zone_id)` |
| 对应图表 | 需求热力图、供需失衡图 |

### 指标 2：全市同期需求强度基准

| 项 | 内容 |
|---|---|
| 名称 | `baseline_demand(t)` |
| 公式 | `D̄(t) = Σ_z duration_h(z,t) / Σ_z pile_cnt(z)` |
| 含义 | 全市该时段的平均需求强度，作为失衡判断基准 |
| 来源表 | `ev.dwd_zone_hour` JOIN `ev.dim_zone_info` |
| SQL | `SELECT hour_ts, SUM(duration_h)/SUM(pile_cnt) FROM ... GROUP BY hour_ts` |
| 对应图表 | 供需失衡图（基准线） |

### 指标 3：峰谷供需失衡指数 ★核心创新点

| 项 | 内容 |
|---|---|
| 名称 | `imbalance_index` |
| 公式 | `I(z,t) = D(z,t) − D̄(t)` |
| 含义 | 该分区该时段需求相对全市平均的偏离。>0 需求偏紧，<0 供给偏富余 |
| 来源表 | 指标 1 与指标 2 相减 |
| SQL | 见下方 Spark 实现 |
| 对应图表 | 供需失衡热力图、Top-N 紧张分区榜 |

### 指标 4：相对失衡率

| 项 | 内容 |
|---|---|
| 名称 | `relative_imbalance` |
| 公式 | `RI(z,t) = I(z,t) / D̄(t)` |
| 含义 | 消除量纲，看相对偏离幅度 |
| 对应图表 | 供需失衡图（辅助） |

### 指标 5：分区峰谷差

| 项 | 内容 |
|---|---|
| 名称 | `peak_valley_gap` |
| 公式 | `PK(z) = max_t D(z,t) − min_t D(z,t)` |
| 含义 | 该分区自身的负荷波动幅度 |
| 对应图表 | 电价弹性对比图 |

### 指标 6：充电桩饱和度

| 项 | 内容 |
|---|---|
| 名称 | `saturation` |
| 公式 | `S(z,t) = D(z,t) / D_max(z)`（相对该分区历史最高负荷） |
| 含义 | 该分区距离"满负荷"还有多远 |
| 对应图表 | 首页指标卡 |

### 指标 7：分时电价区判定

| 项 | 内容 |
|---|---|
| 名称 | `is_tou_pricing` |
| 公式 | 主方案：取 `inf.csv` 标识字段<br>备选方案：`σ_price(z) > 阈值`（电价时序标准差） |
| 含义 | 该分区是否实行分时电价 |
| 对应图表 | 电价弹性对比图 |

### 指标 8：电价弹性系数

| 项 | 内容 |
|---|---|
| 名称 | `price_elasticity` |
| 公式 | `ε(z) = corr(D(z,t), price(z,t)) × sd(D)/sd(price)` |
| 含义 | 电价变动对需求的敏感度 |
| 对应图表 | 电价弹性图 |

### 指标 9：分时电价削峰效果

| 项 | 内容 |
|---|---|
| 名称 | `peak_valley_reduction` |
| 公式 | `(PK_固定电价区均值 − PK_分时电价区均值) / PK_固定电价区均值 × 100%` |
| 含义 | 分时电价使峰谷差下降的百分比 |
| 对应图表 | 电价弹性图（核心结论） |

### 指标 10：需求预测值

| 项 | 内容 |
|---|---|
| 名称 | `forecast_demand` |
| 公式 | 滑动平均 / 同星期同比 / 多元回归（三选一，见第五章） |
| 含义 | 未来时段的预测需求强度 |
| 对应图表 | 预测曲线 |

### 指标 11：预测误差

| 项 | 内容 |
|---|---|
| 名称 | `mape` |
| 公式 | `MAPE = (1/n) Σ |pred − actual| / actual × 100%` |
| 含义 | 预测准确度 |
| 对应图表 | 预测页误差标注 |

### 指标 12：布点扩容建议

| 项 | 内容 |
|---|---|
| 名称 | `expansion_advice` |
| 公式 | 见下方规则表 |
| 含义 | 该分区该采取什么动作 |
| 对应图表 | 布点建议看板 |

## 布点扩容建议规则

| 触发条件 | 建议动作 | 说明 |
|---|---|---|
| `max_t I(z,t) > 全市 P90` | **建议扩容** | 该分区高峰需求显著超全市平均 |
| `PK(z) > 全市 P80` | **建议分时电价引导** | 峰谷差大，价格引导有空间 |
| `I(z,t) < 0 持续 30 天以上` | **建议车辆调度** | 供给长期富余 |
| 周边 POI 以生活/餐饮为主且需求增长快 | **建议新增** | 依赖 POI 分析（可砍项） |

输出字段：`zone_id`、建议类型、建议数量、依据指标值、预期效果。
