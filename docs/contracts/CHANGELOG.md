## 使用规则

1. **任何契约变更都必须在对应文件的「变更记录」表里追加一行**，并更新文件头的版本号
2. 合并到 main 后，同步在这里登记一行
3. 群里发一句"XX 契约升到 vN.N，受影响的是 YY"即可，**不需要粘贴内容**
4. 契约回滚 = git revert，同样要在这里登记
