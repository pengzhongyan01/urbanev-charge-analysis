## 口径（必须记住）

- 底图是**行政区划**（9 个区），数据点是**交通分区**（275 个，出租车 OD 聚类单元）；
- 两套划分**没有对应关系**，所以底图只做空间参考，数据一律按经纬度打点，**不做面填充**；
- 坐标系统 WGS84，直接 `coordinateSystem: 'geo'` 定位。

## 用法（前端）

```js
// 1) 注册底图（只做一次）
const geo = window.UEV_GEO;                       // 已内嵌，file:// 也能用
echarts.registerMap('shenzhen', {
  type: 'FeatureCollection',
  features: geo.features.map(f => ({
    type: 'Feature',
    properties: { name: f.properties.name },
    geometry: {
      type: 'Polygon',
      coordinates: f.geometry.type === 'MultiPolygon'
        ? f.geometry.coordinates.flat() : f.geometry.coordinates
    }
  }))
});

// 2) geo + scatter 两层叠一张图
geo: { map: 'shenzhen', roam: true, itemStyle: { areaColor: '#0f2038', borderColor: '#2f5b86' } },
series: [{ type: 'scatter', coordinateSystem: 'geo', data: [[lon, lat, occupancy]] }]
```

## 配色约定

| 占用率 | 颜色 | 含义 |
|---|---|---|
| > 0.7 | `#ff6b35` | 紧张（3 个分区） |
| 0.4 ~ 0.7 | `#00d4ff` | 正常（38 个分区） |
| < 0.4 | `#22c55e` | 闲置（234 个分区） |
| 无数据 | `#2c4666` | 保留色，当前 0 个分区命中 |

> 2026-11-24 全量重算后，**275/275 个分区全部有数据**（覆盖率 100%），图上不再出现灰色「未覆盖」点。
> 数据来源：`_全量数据\zone_occupancy.csv`（275 行，由官方 `python_etl.py` 全量计算）。

## 三个坑

1. **不要**把 275 个分区画进行政区 GeoJSON，必然对不上；
2. 答辩现场要离线：底图必须放本地 `assets/`，代码里不许写 `https://` 直链；
3. 地图转换失败也别慌，`renderScatterFallback()` 用直角坐标散点能顶上，不白屏。
