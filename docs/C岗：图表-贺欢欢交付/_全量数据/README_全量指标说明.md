## 一、怎么生成的（三条命令，可复现）

```bash
# 1) 下载 12 个原始 CSV（约 129MB，脚本自带重试 + 镜像）
bash scripts/download_data.sh

# 2) 跑全量 ETL（自动探测数据目录，34.8 秒跑完）
python scripts/python_etl.py --data data/raw --out data/etl_out

# 3) 产物即本目录的 12 个 CSV
```

依赖：Python 3.11+、pandas、numpy、scikit-learn（仅用于电价弹性 σ 轮廓系数）。

### 失衡相关两个口径的区别（答辩必答）

- `imbalance_zones` = **有过失衡记录的分区数**，口径是「至少 1 个时段 |区每桩时长 − 全城每桩时长| > 同时刻跨区 1σ」。
  4,344 个小时里每个分区必然有几次越线，所以它恒等于 275/275，只说明「都曾失衡」，不代表都紧张。
- `persistent_imbalance_zones` = **持续紧张分区数**，口径是「失衡时段占全部时段 ≥50%」，全量为 **51 个**，有区分度。
- 首页 KPI 卡展示后者；`imbalance_index.csv` 的 TOP15 则是按失衡**强度**（指数大小）排的前 15 个。
