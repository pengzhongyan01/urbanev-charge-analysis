# C07 · 筛选与导出交互说明

## 一、筛选控件（六页共用一套）

| 控件 | 类型 | 默认值 | 作用范围 | 备注 |
|---|---|---|---|---|
| 时间范围 | 日期区间 | 2022-09-01 ~ 2023-02-28 | 全页 | 起止顺序校验，反了就红字提示 |
| 分区 | 下拉（275 项） | 全部 | 地图 / 预测 / 布点 | 选中后地图打高亮涟漪 |
| 小时 | 下拉 0—23 | 全时段 | 供需 / 失衡 | — |
| 优先级 | 下拉 P1/P2 | 全部 | 布点清单 | 仅 P6 生效 |
| 重置 | 按钮 | — | 全页 | 恢复默认并同步 URL |
| 应用筛选 | 按钮 | — | 全页 | 防抖 300ms，连点只发一次请求 |
| 导出 CSV | 按钮 | — | 当前页 | 跟当前筛选走 |

## 二、状态与 URL

- 筛选状态写入 URL 查询参数：`?start=&end=&zone=&hour=&pri=`，可分享、刷新可还原；
- 筛选变化 → 校验 → `loadAll()` → 全页图表统一刷新；
- 请求结果 5 分钟缓存（key = 参数哈希），来回切筛选不重复打接口。

## 三、导出规则

| 页面 | 导出内容 | 文件名示例 |
|---|---|---|
| 总览 | ads_hourly_supply_demand | `ads_hourly_supply_demand_2022-09-01_2023-02-28.csv` |
| 分区地图 | ads_zone_occupancy | `ads_zone_occupancy_2022-09-01_2023-02-28.csv` |
| 供需分析 | ads_imbalance_index | `ads_imbalance_index_...csv` |
| 电价弹性 | ads_price_elasticity | `ads_price_elasticity_...csv` |
| 需求预测 | ads_demand_forecast | `ads_demand_forecast_...csv` |
| 布点建议 | ads_expansion_suggestion | `ads_expansion_suggestion_...csv` |

技术要点：
1. 数据取 `STATE.data`（不读 DOM），保证「图和表同源」；
2. CSV 加 **UTF-8 BOM**（`\ufeff`），否则 Excel 打开中文乱码；
3. `Blob` + `a.download`，纯前端拼装，**不触发接口请求**，演示不卡顿；
4. 加载中按钮置灰，防重复点击；
5. 图表 PNG 复用 ECharts 的 `getDataURL`：目标宽度 ≈1920（按图表实际宽度反算 1.5~3 倍倍率），背景取深色底；每页导出该页主图，文件名 = 页名 + 筛选区间；图表未初始化时返回 `false`、只提示不报错。

## 四、异常与空态

| 场景 | 处理 |
|---|---|
| 接口不可用 | 降级读本地样例，顶部提示「离线样例数据」，图表照常显示 |
| 筛选后无数据 | 显示空态插画 + 「清除筛选」按钮，不留白屏 |
| 日期非法 | 红字提示，不发起请求 |
| 窗口缩放 | `resize` 事件统一 `chart.resize()` |
