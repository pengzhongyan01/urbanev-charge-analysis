## 二、怎么导入、怎么跑（3 步）

### 1. 导入集合
Postman → Import → 选 `UrbanEV_D岗_16接口.postman_collection.json`

### 2. 确认两个集合变量（集合 → Variables 页签）
| 变量 | 本次实跑值 | 说明 |
|---|---|---|
| `baseUrl` | `http://127.0.0.1:18080/api` | 默认写的是 8080，本机演示端口是 18080，**必须改** |
| `token` | 空 | 由"02 登录"请求自动写入，其余 15 条不用手贴 |

### 3. 跑一遍
- **方式 A**：点集合 → Run → 16 个请求顺序执行（登录在前，后续请求自动带 token）
- **方式 B**：逐个点 Send，从 01 开始按顺序（本批 16 张截图就是这样一张张点出来的）

**命令行跑（不需要开 Postman 界面）**：
```powershell
newman run "UrbanEV_D岗_16接口.postman_collection.json" --env-var "baseUrl=http://127.0.0.1:18080/api"
```

## 三、断言是怎么写的

每个请求末尾都挂同一个断言（示例取自"04 KPI 概览"）：

```javascript
pm.test("code = 200", function () {
    pm.response.to.have.status(200);                  // HTTP 层必须 200
    const json = pm.response.json();
    pm.expect(json.code).to.eql(200);                  // 业务层必须 200
    pm.expect(json).to.have.property("timestamp");     // 四字段完整
});

pm.test("KPI 口径一致", function () {
    const d = pm.response.json().data;
    pm.expect(d.stationCount).to.eql(275);             // 契约硬约束
    pm.expect(d.pileCount).to.eql(23441);              // 与数据字典口径一致
    pm.expect(d.avgOccupancy).to.be.within(0, 1);      // 必须是 0-1 比例
});
```

**登录请求额外一段**，把令牌写进集合变量，后面 15 个请求就不用手工粘贴：
```javascript
const json = pm.response.json();
if (json.code === 200) pm.collectionVariables.set("token", json.data.token);
```

**为什么要断言 275 / 23441 / 0-1**：
这三个是契约里写死的口径，也是最容易被"改着改着改坏"的地方（例如有人把桩数改成"去重后的站数"）。
把它们写成断言，以后任何一次回归都会立刻发现口径漂移。

## 五、这 16 张截图是怎么来的（可复现）

```
Postman 12.38（本机，程序在 D:\Postman\PostmanApp，数据在 D:\PostmanData\Postman）
        │  导入集合 → 集合变量 baseUrl 改成 http://127.0.0.1:18080/api
        ▼
逐条双击请求 → 点 Send → 看到 200 OK + JSON 正文
        │  截全屏（1920×1080）→ 裁到 Postman 窗口（去掉桌面图标/任务栏）→ LANCZOS 放大到 2400px
        ▼
D10/实测响应_NN_xxx.png   ← 2400×1786，PNG，含"选中的请求名 + 真实 URI + 200 OK + JSON"
```

**两个细节**：
- **不裁响应体凑数**：长响应（05/06 各 36 KB）在截图里只能看到滚动的头部，`结论.md` 里明确写了总条数（275 条），不假装一张图装得下全部。
- **不重排、不补字**：截图里的耗时和体积都是 Postman 自己测出来的原值（12 ms—397 ms），报告里引用的就是这些数字。

## 六、换机器怎么跑（配合 D14）

1. 改集合变量 `baseUrl` 为本机地址（端口跟着 `--server.port` 走）
2. 若开了鉴权（`--uev.auth.enabled=true`），先跑 02 登录（会自动写 token）
3. 若数据库没导入，先跑 `01_schema.sql` + `02_seed_mock.sql`（见 D03）
4. 一键回归：`scripts/smoke_test.ps1 -Base http://localhost:8080/api`（15 项断言，见 D11）
