## 截图是真的，不是画出来的

16 张图全部来自本机 Postman 12.38 的实际运行：导入集合 → 把集合变量 `baseUrl` 改成 `http://127.0.0.1:18080/api`
→ 逐条点 Send（02 登录先跑，自动把 token 写进集合变量）→ 全屏截图 → 裁到 Postman 窗口 → 放大到 2400px。

> 每张图上都能看见三样东西：左侧集合树里被选中的那条请求名、顶部的**真实 URI**（`{{baseUrl}}/…`）、
> 右下 `200 OK · 耗时 · 响应体积` 和返回的 JSON 正文。也就是说，任何一个数字都能当场复核。
