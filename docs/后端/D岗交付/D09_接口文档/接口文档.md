## 0. 通用约定

### 0.1 统一响应

```json
{ "code": 200, "message": "success", "data": {...}, "timestamp": 1795160027232 }
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | int | 200 成功 / 400 参数错 / 401 未认证 / 403 无权限 / 404 不存在 / 405 方法不支持 / 500 内部错 / 503 依赖不可用 |
| `message` | string | 失败时**直接展示给用户**的中文提示 |
| `data` | object / array | 失败时为 `null`（JSON 里不出现） |
| `timestamp` | long | 服务端毫秒时间戳（**不是数据时间**，别显示在 UI 上） |

> **HTTP 状态码恒为 200**（原因见 D02：前端 `common.js` 遇到 `!res.ok` 会丢掉中文提示）。

### 0.2 鉴权

- 受保护接口需带 `Authorization: Bearer <token>`。
- 默认 `uev.auth.enabled=false`（联调期放行）；答辩演示时加 `--uev.auth.enabled=true` 打开。

### 0.3 公共查询参数

| 参数 | 类型 | 约束 | 默认 | 说明 |
|---|---|---|---|---|
| `startDate` | string | `yyyy-MM-dd` | 无 | 起始日期（**见 0.4 边界**） |
| `endDate` | string | `yyyy-MM-dd`，≥ startDate | 无 | 结束日期（同上） |
| `hourRange` | string | `H-H`，起始 ≤ 结束，0~23 | 无 | 小时区间，如 `8-18` |
| `zoneId` | string | ≤10 字符 | 无 | 分区编号 |
| `priceType` | string | `TOU` / `FLAT` | `TOU` | 电价类型 |
| `limit` | int | 1~100 | 10（分区列表为 6） | 返回条数 |

### 0.4 ⚠️ 已知边界：日期参数不生效

ADS 层是**全期聚合表**（`occupancy.csv` 等只有"分区 × 小时"两个维度，没有日期维度）。
因此 `startDate` / `endDate` **仅作为接口签名保留**（前端会传、后端会校验格式），
但**不会过滤数据**。实际生效的过滤条件是 `zoneId` / `hourRange` / `limit`。

> 这不是 bug，是数据源决定的。已同步给 C 岗，避免前端做"选日期→数字不变"的困惑。
> 若后续 ADS 增加 `dt` 分区，只需改视图加 `dt >= #{startDate}`，前端无感。

## 1. `GET /api/health` —— 健康检查

**参数**：无

**响应**
```json
{
  "code": 200, "message": "success",
  "data": {
    "status": "UP",
    "timestamp": "2026-11-20T15:35:36",
    "application": "uev-charge-analysis",
    "version": "1.0.0",
    "regionCount": 275,
    "components": { "mysql": "UP", "redis": "DOWN" }
  }
}
```
| 字段 | 说明 |
|---|---|
| `status` | `UP` 全部正常 / `DEGRADED` 部分组件异常 |
| `components.redis` | 未装 Redis 时为 `DOWN`（**设计性降级，接口不受影响**，见 D13） |
| `regionCount` | 固定 275（契约要求的校验点） |

```bash
curl -s http://localhost:8080/api/health
```

## 2. `POST /api/auth/login` —— 登录

**请求体**
```json
{ "username": "admin", "password": "uev123456" }
```
| 字段 | 必填 | 说明 |
|---|---|---|
| `username` | 是 | 账号（`admin` / `analyst`） |
| `password` | 是 | 密码（演示为 `uev123456`） |

**响应**
```json
{
  "code": 200, "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9....（实际 172 字符）",
    "tokenType": "Bearer",
    "expiresIn": 7200,
    "user": { "username": "admin", "realName": "杨姗姗", "roleCode": "ADMIN" }
  }
}
```
**错误**：密码错/账号不存在 → `code 401`「用户名或密码错误」（**不区分是哪一项**）

```bash
curl -s -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d "{\"username\":\"admin\",\"password\":\"uev123456\"}"
```

## 3. `GET /api/auth/me` —— 当前用户

**Header**：`Authorization: Bearer <token>`

**响应**
```json
{ "code": 200, "data": { "username": "admin", "realName": "杨姗姗", "roleCode": "ADMIN" } }
```
**错误**：无令牌 → `401`「未携带令牌，请先登录」；令牌无效/过期 → `401`「令牌已失效，请重新登录」

## 4. `GET /api/dashboard/kpi` —— 首页 KPI

**参数**：无

**响应**（完整见 `mock/04_kpi.json`）
```json
{
  "code": 200,
  "data": {
    "stationCount": 275,
    "pileCount": 23441,
    "avgOccupancy": 0.4587,
    "totalVolume": 904822.6,
    "avgDuration": 2.8765,
    "imbalanceZones": 23,
    "regions": [ { "zoneId": "140", "pileCount": 310 }, ... ]
  }
}
```
| 字段 | 单位/口径 |
|---|---|
| `avgOccupancy` | **0-1 比例**，显示百分比需 ×100 |
| `totalVolume` | kWh |
| `avgDuration` | 小时 |
| `imbalanceZones` | 存在失衡的分区数，与 `/charts/imbalance?limit=23` 行数一致 |
| `regions[]` | 桩数 TOP6 分区，给首页小图用 |

## 5. `GET /api/zones` —— 分区列表

**参数**：`limit`（1~100，默认 6）

**响应**
```json
{ "code": 200, "data": { "total": 275, "zones": [
  { "zoneId": "297", "longitude": 114.16122, "latitude": 22.72684,
    "avgOccupancy": 0.7777, "maxOccupancy": 0.9664, "chargeCount": 83, "poiTotal": 394 } ] } }
```
- `total` 是**全量 275**，不是当前页条数（前端分页显示"共 275 条"用它）
- `zoneId` 是**字符串**

## 7. `GET /api/zones/{zoneId}` —— 分区详情

**路径参数**：`zoneId`

**响应**
```json
{
  "code": 200,
  "data": {
    "zone": { "zoneId": "140", "avgOccupancy": 0.1399, "maxOccupancy": 0.2248, "chargeCount": 310, "poiTotal": 2252, ... },
    "peakHours": [
      { "hourOfDay": 18, "avgOccupancy": 0.2273 },
      { "hourOfDay": 17, "avgOccupancy": 0.2116 }
    ]
  }
}
```
- `peakHours` 取占用率 TOP5，按降序
- **错误**：不存在 → `404`「分区 999 不存在」

## 8. `GET /api/charts/hourly` —— 24 小时供需曲线

**参数**：`hourRange`（如 `8-18`）

**响应**
```json
{ "code": 200, "data": [
  { "hourOfDay": 0, "avgOccupancy": 0.31, "avgDemand": 0.02, "avgSupply": 0.04, "gap": -0.02, "imbalance": 0.05 } ] }
```
- `avgDemand` / `avgSupply` 是**份额（0-1）**，不是绝对值
- `gap = demand - supply`，负数表示供大于求
- **错误**：`hourRange=19-17` → `400`「hourRange 起始小时不能大于结束小时」

---

## 9. `GET /api/charts/imbalance` —— 供需失衡 TOP

**参数**：`limit`（≤100）、`zoneId`（可选）、`hourRange`（可选）

**响应**
```json
{ "code": 200, "data": [
  { "zoneId": "297", "longitude": 114.16122, "latitude": 22.72684, "hourOfDay": 18,
    "demandShare": 0.0031, "supplyShare": 0.0002, "imbalance": 0.0029, "rankNo": 1 } ] }
```
- `rank_no` 用**数据库里 E 岗算好的排名**，后端不重算，保证口径一致
- **错误**：`limit=999` → `400`「limit 最大值为 100」

---

## 10. `GET /api/charts/price-elasticity` —— 电价弹性双曲线

**参数**：`priceType`（`TOU` / `FLAT`，可选，不传则返回两组）

**响应**
```json
{ "code": 200, "data": {
  "TOU":  [ { "hourOfDay": 0, "avgOccupancy": 0.28 }, ... 24 点 ],
  "FLAT": [ { "hourOfDay": 0, "avgOccupancy": 0.33 }, ... 24 点 ]
} }
```
- 返回结构是**对象不是数组**：前端 ECharts 需要两条 series，后端一次给两组，省掉前端 split

---

## 11. `GET /api/charts/forecast` —— 需求预测

**参数**：`zoneId`、`startDate`、`endDate`、`limit`

**响应**
```json
{ "code": 200, "data": {
  "zoneId": "140", "mape": 8.62,
  "series": [ { "forecastDate": "2025-10-01", "hourOfDay": 0, "predictVolume": 123.4, "actualVolume": 118.7 } ]
} }
```
- 单分区 7 天 × 24 小时 = **168 行**
- 库里只有 **140 / 145 / 152** 三个分区有预测；其它 → `404`「该分区暂无预测数据」
- `mape` 是百分数（`8.62` 表示 8.62%）

---

## 12. `GET /api/charts/suggestions` —— 布点扩容建议

**参数**：`limit`

**响应**
```json
{ "code": 200, "data": [
  { "zoneId": "297", "longitude": 114.16122, "latitude": 22.72684,
    "currentPiles": 83, "suggestedPiles": 10, "priority": 1,
    "reason": "该分区在 18 时出现供需失衡（失衡指数 0.0029），现有 83 个充电桩，建议新增 10 个桩",
    "avgOccupancy": 0.7777, "peakGap": 0.002866 } ] }
```
- **`suggestedPiles` 是"建议新增数"**，不是建议总数（83 + 10 = 93）
- 表格列名请写「建议新增(个)」
- `reason` 是**完整中文句**，前端直接显示，不要再拼"建议："前缀

## 附录 A：错误码速查

| code | 触发示例 |
|---|---|
| 400 | `?limit=999`、`?hourRange=19-17`、`?startDate=2025-13-01`（日期格式非法） |

| 503 | MySQL 停机且缓存未命中 |
