## 验收标准

- [x] TTL 与契约 03 一致：kpi **300s**、zone_occ **600s**、charts **120s**
- [x] 有"命中 vs 未命中"的**同接口对比**数据（不是拿两个接口比）
- [x] 有服务端耗时与 HTTP 端到端耗时两组数据（说明"缓存省的是哪一段"）
- [x] Redis 连不上时**自动降级为本地缓存**，接口不报错，有日志原文
- [x] 缓存命中可审计：`query_log.hit_cache` 字段能证明"这次走没走缓存"
- [x] Key 设计防穿透：`前缀 + MD5(方法名 + 全部入参)`，不同参数不串号

## 核心数据（一表看完）

| 指标 | 未命中（回源 MySQL） | 命中缓存 | 提升 |
|---|---|---|---|
| 服务端平均耗时 | **1.952 ms** | **0.003 ms** | **650.7×** |
| HTTP 端到端耗时 | 9.1 ms | 6.1 ms | 节省约 33% |
| query_log 记录耗时 | 31 ms | 2~3 ms | 约 10× |
