## 3. 怎么做（命令可直接照抄）

### 3.1 环境变量（当前窗口有效）
```powershell
$env:JAVA_HOME = 'C:\Users\Rarit\devtools\jdk\jdk-17.0.21+9'
```

永久生效：`setx JAVA_HOME "C:\Users\Rarit\devtools\jdk\jdk-17.0.21+9"`，再把 `%JAVA_HOME%\bin` 与 Maven `bin` 加进 PATH。

### 3.2 建库 + 灌数据（B 岗真数据没来之前就靠它）
```powershell
cd 杨姗姗_D岗交付
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS uev_charge DEFAULT CHARSET utf8mb4;"
mysql -u root -p uev_charge -e "source C:/temp/sql/01_schema.sql"
mysql -u root -p uev_charge -e "source C:/temp/sql/02_seed_mock.sql"
mysql -u root -p uev_charge -e "source C:/temp/sql/04_auth_seed.sql"
```
> ⚠️ `source` 遇到**中文路径**会报 `Failed to open file`。先把 sql 拷到 `C:\temp\sql\` 再执行（本机踩过）。
> 导入后应看到：`zone_occupancy` 275 行、桩数合计 23441、`dashboard_kpi` 1 行、`zone_hour_profile` 6600 行、14 表 + 10 视图。

### 3.3 编译 + 单测
```powershell
cd backend
mvn -B clean package
```
期望：
```
Tests run: 7, Failures: 0, Errors: 0, Skipped: 0
BUILD SUCCESS
```

### 3.4 启动（推荐用脚本，自动查环境/端口/健康检查）
```powershell
# 自检（不启动）
.\D14_第二台机器启动验证\start.ps1 -Check
# 启动（换端口/换密码都走参数）
.\D14_第二台机器启动验证\start.ps1 -Port 8080 -DbPassword "你的root密码"
# 停止
.\D14_第二台机器启动验证\start.ps1 -Stop -Port 8080
```
也可以直接：
```powershell
java -jar backend\target\uev-charge-analysis.jar --server.port=8080 --uev.cache.type=local
```

### 3.5 自检 16 个接口
```powershell
pwsh -File scripts\smoke_test.ps1 -Base http://127.0.0.1:8080/api
```
实测：`结果：通过 15　失败 0`（`/auth/me` 需令牌，单独测）。
