## 这一项放什么

| 文件 | 说明 |
|---|---|
| `start.ps1` | 一键启动/停止/自检脚本：查 JDK17、查 jar、查端口、查 MySQL、启动、轮询健康检查 |
| `第二台机器启动验证.md` | 验证清单 + 步骤 + 5 个常见坑 + 记录表（第二台机器跑完填表即交） |

## 为什么这一项会被要求

参考作业的硬伤之一：**绝对路径硬编码 D 盘** —— 换台机器就起不来。
所以这一项要证明：**这套后端不依赖任何一台特定机器**。

## 验收标准

- [x] `start.ps1` 里**零绝对路径**（用 `$PSScriptRoot` / `$MyInvocation.MyCommand.Path` 相对定位）
- [x] 端口、数据库地址、账号、密码、缓存模式全部是**参数**，不写死
- [x] JDK 版本不对 → 中文提示并退出，不会跑到一半才报 `UnsupportedClassVersionError`
- [x] 启动后**自动轮询** `/api/health`，60 秒内不通就报失败并打印日志尾部（不假装成功）
- [x] 提供 `-Stop` 按端口停服务，不用去任务管理器找 PID
- [x] 本机（Windows + JDK17 + MySQL8）实测通过；第二台按文档 6 步执行并填记录表
