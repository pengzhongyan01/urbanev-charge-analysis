## 为什么这一项是"证据"而不是"说明"

老师最不信的一句话是"我们做了异常处理"。所以这一项**全部是原始日志和原始响应**，
不是我总结的结论 —— 结论只占最后一节。

## 验收标准

- [x] 三类故障**真停真测**：Redis 不可用、MySQL 停机、非法参数/错误路径
- [x] 每类都有日志原文（带时间戳、线程号），不是转述
- [x] 会挂的只有"未缓存且需查库"的请求；已缓存数据仍能返回，看板不整体瘫
- [x] 故障恢复后无需重启应用（Redis 探活失败只是降级，不是退出）
- [x] 503 而不是 500 —— 让使用者知道"是数据库的事，不是程序崩了"
