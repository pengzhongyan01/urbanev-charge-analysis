## 二、⚠️ 关键问题：9 个行政区 ≠ 275 个交通分区

这是最容易做错、也最容易被老师问的一点：

| | 数量 | 例子 |
|---|---|---|
| **行政区划**（GeoJSON 里的） | **9 个** | 南山区、福田区、罗湖区… |
| **交通分区**（数据里的 `zone_id`） | **275 个** | 102、104、1066、1085… |

**它们是完全不同的划分体系**：
- 行政区划是**政府管理口径**（9 个区）
- 交通分区是**交通流分析口径**（275 个单元，源自出租车 OD 数据聚类得到的交通小区）

**结论：不要试图把 275 个分区画进这个 GeoJSON 里，会对不上。**

---

## 三、正确的做法（推荐：分区散点图 + 行政区轮廓作底）

### 方案 A（推荐，最稳妥）：行政区轮廓 + 275 分区散点

**视觉上呈现**：
- 底图：深圳 9 个行政区的浅色轮廓线（`lines` 类型，`zlevel` 最低）
- 数据层：275 个分区的散点/热力点（`scatter` 或 `heatmap`），**按经纬度定位**

**为什么可行**：我们的 `zone_occupancy` 表里本来就有每个分区的 `longitude` 和 `latitude`，
直接用 `coordinateSystem: 'geo'` 定位即可，**不需要分区和行政区划建立对应关系**。

#### 实现步骤

**第 1 步：注册地图**（在 `frontend/js/app.js` 的 `loadHeatmap` 之前调用一次）

```javascript
// 加载行政区轮廓作为底图
async function loadBaseMap() {
    if (echarts.getMap('shenzhen')) return;   // 已加载过

    const res = await fetch('assets/shenzhen_440300_full.json');
    const geoJson = await res.json();

    // 关键：把 GeoJSON 转成 ECharts 5 的格式
    echarts.registerMap('shenzhen', {
        type: 'FeatureCollection',
        features: geoJson.features.map(f => ({
            type: 'Feature',
            properties: { name: f.properties.name },
            geometry: {
                type: 'Polygon',
                coordinates: f.geometry.coordinates
            }
        }))
    });
}
```

> ⚠️ **ECharts 5 不直接支持阿里 DataV 的 `MultiPolygon` 嵌套结构**，
> 上面这段做了转换。如果遇到 `MultiPolygon`，坐标需要再展平一层：
> ```javascript
> coordinates: f.geometry.type === 'MultiPolygon'
>     ? f.geometry.coordinates.flat()      // 展平一层
>     : f.geometry.coordinates
> ```

**第 2 步：图表配置**

```javascript
STATE.charts.heatmap = initChart('chartHeatmap', baseOption({
    geo: {
        map: 'shenzhen',
        roam: false,
        itemStyle: {
            areaColor: '#0f2038',      // 区域填充色
            borderColor: '#1e3a5f',    // 边界线
            borderWidth: 1
        },
        emphasis: {
            itemStyle: { areaColor: '#1a3a5f' },
            label: { show: false }
        },
        label: { show: false }
    },
    series: [{
        type: 'scatter',
        coordinateSystem: 'geo',
        symbolSize: d => 5 + d[2] * 14,       // 按占用率调整点大小
        data: zones.map(z => [z.longitude, z.latitude, z.avgOccupancy]),
        itemStyle: {
            color: p => {
                const t = p.value[2] || 0;
                if (t > 0.7) return '#ff6b35';   // 紧张
                if (t > 0.4) return '#00d4ff';   // 正常
                return '#22c55e';                 // 闲置
            },
            opacity: 0.85
        },
        emphasis: { scale: 1.5 }
    }]
}));
```

**第 3 步：tooltip 展示分区信息**

```javascript
tooltip: {
    trigger: 'item',
    formatter: p => {
        const z = zones[p.dataIndex];
        if (!z) return '';
        return `<b>分区 ${z.zoneId}</b><br>` +
               `占用率：${formatPercent(z.avgOccupancy)}<br>` +
               `充电桩：${z.chargeCount} 个<br>` +
               `POI 总数：${z.poiTotal || '--'}`;
    }
}
```

### 方案 B：纯散点图（不依赖任何地图文件）

如果地图转换遇到麻烦，**直接用散点图也完全能过**——
答辩时讲"这是深圳 275 个交通分区的空间分布"，
配一张深圳轮廓作为底（方案 A 的 geo 部分）就够了。

散点图的核心配置（无 geo 注册要求）：

```javascript
xAxis: { type: 'value', name: '经度', min: 113.7, max: 114.6,
          axisLabel: { color: '#8fa8c8' } },
yAxis: { type: 'value', name: '纬度', min: 22.4, max: 22.9,
          axisLabel: { color: '#8fa8c8' } },
series: [{
    type: 'scatter',
    symbolSize: d => 6 + d[2] * 16,
    data: zones.map(z => [z.longitude, z.latitude, z.avgOccupancy]),
    itemStyle: { color: '#00d4ff' }
}]
```

> 这正是 `frontend/js/app.js` 里已经写好的 `renderScatterFallback()` 降级方案，
> **你现在不写地图也不会白屏**。
